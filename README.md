# 🌡️ Temperature Conversion Program

A temperature conversion program developed as part of Task 01 of my Software Development Internship at Prodigy InfoTech.

## Task Objective

Build a program that converts temperatures between Celsius, Fahrenheit, and Kelvin.

The program accepts a temperature value and its original unit, then converts it into the other two temperature scales.

## Features

- Celsius to Fahrenheit and Kelvin conversion
- Fahrenheit to Celsius and Kelvin conversion
- Kelvin to Celsius and Fahrenheit conversion
- Input validation
- Kelvin absolute-zero validation
- Clear/reset functionality
- Responsive user interface
- Enter-key support
- Results displayed up to two decimal places

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Conversion Formulas

### Celsius to Fahrenheit

F = (C × 9/5) + 32

### Celsius to Kelvin

K = C + 273.15

### Fahrenheit to Celsius

C = (F − 32) × 5/9

### Fahrenheit to Kelvin

K = (F − 32) × 5/9 + 273.15

### Kelvin to Celsius

C = K − 273.15

### Kelvin to Fahrenheit

F = (K − 273.15) × 9/5 + 32

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code.
